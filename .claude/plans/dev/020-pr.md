**Title:** chore: plan 020 — conventions: comments, scope, dead code

## Summary

Follow-up to the review note that comments run too long and code gets added "for later". This PR tightens the rules Claude follows and cleans up what they flag. There's no behavior change.

### Rules (`.claude/CLAUDE.md`)
- "Conventions" is replaced by two sections:
  - **Mandatory conventions** covers comments and docblocks. Comments are only for a quirk, a workaround, or why not the obvious way. They never record decisions, plans or history, and never restate the code. Docblocks get one line of purpose and typed `@param`s.
  - **Scope and dead code** says to write only what the task uses and not to add helpers, options or hooks "for later". Delete anything you added that has no caller, leave no commented-out code, and add no fallbacks or compat code before v1.0. Unused code you notice outside the task gets listed in the report, not deleted.
- Also added: no plan or checkpoint numbers in code, and CLAUDE.md has no net growth (detail goes in `.claude/docs`).

### Docs (`.claude/docs/`)
- `context-php-backend.md` and `context-dev-convention.md` are trimmed: history, examples and anything the code already says are gone; paths, contracts and commands stay.
- The "catalog keys are only added" line is removed (it's a compat rule).
- The dev convention doc now branches off `develop` and saves plans in `.claude/plans/dev/`.

### Skills
- `/wdev`: new comment rule, a pre-review step to "search for every symbol you added; delete any with no caller", and PRs target `develop`.
- `/wplan`: saves plans to `.claude/plans/dev/` (gitignored, not committed) with base branch `develop`.

### Code
- `phpcs.xml` now excludes `Squiz.Commenting.LongConditionClosingComment`. The 18 `//end if` / `//end try` comments that phpcbf had added are removed.
- ESLint `no-console` added to the admin app (`warn` and `error` allowed). There were no hits.
- Milestone numbers (M2, M2.2, M2.3, F1.6) are removed from 7 comments, along with the "comes in a later milestone" sentences around them.

### Checks
`pnpm build`, `pnpm lint`, `pnpm test` (206), `pnpm test:php` (452), and `pnpm lint:php` all pass.
