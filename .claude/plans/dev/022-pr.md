**Title:** chore: plan 022 — cleanup sweep

## Summary

Applies the CLAUDE.md "Mandatory conventions" and "Scope and dead code" rules to the existing code. Comments are trimmed to quirks, workarounds and why-not-obvious notes. Docblocks are cut to one line of purpose and typed `@param`s. Dead code goes, and so does the pre-v1.0 compat code: before v1.0, dev data is reset, not migrated. Nothing else changes behavior.

## Before you pull (other dev sites)
- **Run `./run.sh drop-legacy` first** if the site still has pre-rename YayAutomation data. This PR deletes the script.
- **Drop the claims table by hand** (optional, it's unused now): `wp db query "DROP TABLE IF EXISTS wp_yaymatik_trigger_claims"` (use your table prefix). There's no DB version bump and no DROP code.
- **Recreate any workflow made before versions existed.** Version seeding is gone, so such a workflow has no live version and doesn't run.

## Decisions
- **D1:** Keep `YayMatikProLicenseAdapter`; only its commented-out code goes.
- **D2:** Delete version seeding. Dev sites recreate workflows made before versions existed.
- **D3:** Delete the Scope `vars` and `workflow` sections and `set_var()`; `run` stays. The Validator already rejects `{{ vars.x }}`.
- **D4:** Leave `components/ui`, `components/motion-ui` and the unused deps alone; they're listed below.
- **D5:** Keep `schemaVersion` and the "newer version" check.
- **D6:** Delete the test-only `Type` API.
- **D7:** Delete `ClaimStore` and the `trigger_claims` table from `Schema`, with no DB version bump and no DROP code.
- **D8:** Keep `Field::number_unit()` / `max()` with the TS widget, and the runs REST + `RunPresenter` + TS run types: M2 uses them.
- **D9:** GenerateCoupon: a missing `code_prefix` is no longer special-cased to `YM`. It reads as `''`, like any text field.
- **D10:** Delete the other compat paths: `mark_activated()` in deactivate, `AddOrderNote::sanitize()` and `dev/scripts/drop-legacy.sh`.
- **D11:** Keep the re-sanitize on read in `WorkflowRepository::decode_graph()`. Its comment is now a current fact.

## Behavior changes
All of them remove pre-v1.0 compat code or unused API:
- **Version seeding:** `has_versions` / `seed_versions` / `ensure_versions`, the seed branch in `RestAPI::list_versions` and seeding in `RepositoryWorkflows::live_version_id` are gone. `VersionStore::insert()` always uses the current user and the current time.
- **`activated_at` backfill:** deactivate no longer calls `mark_activated()`. `to_array()` reads `everActivated` from the meta alone.
- **GenerateCoupon:**
  - Only `null` means "none" for a number field. `''` now reads as the field default (expiry 30). The editor sends `null` for a blank field.
  - A missing `code_prefix` reads as `''` in PHP. The TS `normalize()` still falls back to `YM`, and the editor and templates always send the key.
  - The TS `toNumber` string branch is gone.
- **AddOrderNote:** `sanitize()`, which kept the old key order, is gone. No test pins the order.
- **`ClaimStore` + the `trigger_claims` table:** deleted, with their lines in `check-storage.sh`.
- **Scope `vars` / `workflow`:** deleted. A trigger key named `vars` or `workflow` would now work as a shortcut; no trigger has one.
- **Docs URL filter:** `yaymatik_workflow_runs_docs_url` is gone. The localized `docs.workflowRuns` is the plain URL.
